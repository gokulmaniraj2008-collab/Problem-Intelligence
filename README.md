# Problem Intelligence

Find what people actually need before deciding what to build.

## MVP

Problem Intelligence is a problem-first, evidence-first platform for collecting real-world problems, validating them with people, scoring business opportunity, and eventually choosing the right solution technology.

### Core principle

> AI proposes. Humans verify. Customers decide. Money proves.

### Current MVP

- Problem capture form
- Source and category tagging
- Problem-first workflow
- Responsive premium UI
- Local persistence for early MVP testing

### Planned

- Supabase PostgreSQL
- AI-assisted analysis
- Human validation evidence
- Weighted opportunity scoring
- SIH problem imports
- Solution builder for software, AI, sensors, hardware, robotics, and services

## Development

Built with Next.js, React, TypeScript, and Tailwind CSS.
